# DSH 模型中断提醒

[English](README.md) | 中文

模型运行失败后，自动继续原 DSH 会话，或通过角落提醒手动确认。自动继续默认开启，通过原会话的正常消息路径提交固定文本 `继续`。

插件详情页提供即时生效的开关。提醒跟随 DSH 主题，并排除委派子 Agent。

## 文档

- [安装、行为、隐私与开发](docs/guide.zh.md)
- [GitHub 发布与 dsh-market 收录](docs/publishing.zh.md)
- [MIT 许可证](LICENSE)

插件使用 DSH 扩展服务，不包含游戏逻辑、公司系统集成、账号配置或会话数据。继续运行会沿用会话已有的模型服务与上下文；插件不增加独立上报地址。
